MergeMate analyses GitHub pull requests and uses ProofLayer to distinguish AI suggestions from findings supported by real code evidence.

01 · Ingest

Real GitHub PRs

Fetches metadata, changed files and patches via the GitHub REST API. Public repos work without a token.

02 · Analyse

Deterministic + AI

Static rules catch secrets and bare excepts. An optional AI reviewer adds structured observations — always labelled.

03 · Verify

ProofLayer

Every finding is checked for file path, evidence and support. AI-only claims stay unverified.

Signature technology

ProofLayer

AI reviewers can invent line numbers and sound confident. ProofLayer is an independent validation pipeline that records what was checked and what remains uncertain.

  • ● supported_by_static_check — deterministic rule + concrete evidence
  • ● unverified — AI observation without independent proof
  • ● needs_human_review — incomplete or ambiguous evidence
  • ● rejected — invalid file reference

Existence of a file or line reference is not treated as proof of a defect.
