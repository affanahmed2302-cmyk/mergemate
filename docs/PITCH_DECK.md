2. **Problem** — Confident noise, false accusations, no evidence trail
3. **Solution** — Ingest → Analyse → Verify → Report
4. **ProofLayer** — 5-step Review Replay + status legend
5. **Live demo** — What judges will see (labelled demo path)
6. **Architecture** — Frontend, FastAPI, GitHub, AI mock, security
7. **Impact & limits** — Honest scope control
8. **Close** — “We built a way to check whether an AI review deserves to be trusted.”
