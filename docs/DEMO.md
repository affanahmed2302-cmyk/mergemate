# Demo script (≈ 3 minutes)

1. Open the UI → click **Run labelled demo**.
2. Show summary cards: findings, static-supported, AI unverified, human review.
3. Open **Intelligence Scorecard** and **Risk** — point at the formula and disclaimer.
4. Expand a deterministic finding → open **ProofLayer — Review Replay** and walk the 5 steps.
5. Expand the AI finding → show status is **unverified** (never claimed verified).
6. Mention the correct helper change is not falsely flagged.
7. Click **Useful / Incorrect** on a finding (feedback loop).
8. Download Markdown report.

**Closing line:**

> We didn’t build another AI code reviewer. We built a way to check whether an AI review deserves to be trusted.
