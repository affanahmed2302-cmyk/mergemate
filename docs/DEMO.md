# Demo script (≈ 3 minutes)

1. Open http://localhost:3000
2. Click **Run labelled demo**
3. Show summary cards (findings, static-supported, unverified AI, risk)
4. Open a deterministic finding → evidence + ProofLayer `supported_by_static_check`
5. Open the AI finding → status `unverified`
6. Show “Correct change – no issue found” (false-accusation avoidance)
7. Export Markdown / JSON

Core message: *We built a way to check whether an AI review deserves to be trusted.*
